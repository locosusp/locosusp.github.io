# LocoSusp Project Website

A self-contained static research project page for **LocoSusp: Learning Virtual Suspension for Stable Wheeled-Legged Mobile Platforms**.

## Structure

- `index.html` — main project page
- `assets/css/style.css` — responsive visual system
- `assets/js/main.js` — scroll reveal, mobile navigation, figure lightbox
- `assets/img/` — web-optimized versions of the supplied research figures
- `paper/LocoSusp-final.pdf` — manuscript linked from the page
- `figs/` — original supplied PDF figures, preserved as source assets

## Deploy to GitHub Pages

Upload the contents of this directory to the root of your GitHub Pages repository and enable **Settings → Pages → Deploy from a branch**. No build step or external JavaScript dependency is required.

## Notes

The supplied project did not contain a code repository URL or demonstration video, so the page intentionally labels code as **Coming soon** rather than inventing a link. Replace that button with the final repository URL when available.
